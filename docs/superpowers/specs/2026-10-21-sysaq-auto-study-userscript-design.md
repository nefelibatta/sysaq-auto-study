# 实验室安全教育平台自动学习油猴脚本 — 设计文档

- 日期：2026-10-21
- 状态：已评审
- 目标站点：`https://sysaq.ustc.edu.cn/lab-study-front/examTask/*`

## 1. 背景与目标

USTC 实验室安全教育平台的“学习详情”页按章节展示 PDF/PPT 课程，并统计每篇文档的“已学习 / 要求学习”时长。平台不会在当前文档达标后自动进入下一章，用户需要持续盯着页面手动切换。

本工具是一个**油猴脚本**，在用户已登录的浏览器中运行，做到：

1. 保持当前文档打开，让平台正常累计学习时长；
2. 每 60 秒自动翻一页 PDF/PPT，模拟持续阅读；
3. 当前文档达到要求时长后，自动切换到下一章节；
4. 全部章节完成后停止并通知，不进行任何考试相关操作。

## 2. 目标站点事实（2026-10-21 实测）

- 前端为 Vue 2 + iView 的单页应用，脚本需处理客户端路由切换，不能依赖页面刷新。
- 章节列表：左侧 `.m-left` 内的 `li.panelItem`，当前项带 `.activeitem`，标题在 `.itemTitle`。
- 文档进度：右侧 `.positionRight`，文本格式为 `已学习 <时长> 要求学习 <时长>`，例如 `已学习 12:01 要求学习 30:00`。
- 总进度：顶部 `.m-center .time`，含 `01:55:48 / 03:00:00`（必学）与选学时长。
- 阅读器：`.pptbox`，PDF 按页渲染为 `.vue-pdf-embed__page canvas`；分页栏 `.pageBtn` 内包含“上一页”、页码指示 `1 / 22`、“下一页”。
- 计时机制：文档页打开期间，前端约每 60 秒发起一次 `POST /api/study_upload/{id}`；平台提示“学习时长会在学习完成后 5 分钟更新”。
- 页面顶部有“模拟考试 / 开始考试”按钮，本工具永不点击。
- 同一页面可同时存在 3 个必学章节；每篇文档要求时长可能为 30 分钟，总要求 3 小时，二者不必相等。

> 平台改版会破坏上述选择器。所有选择器集中在 `src/selectors.js`，找不到关键元素时进入异常状态而不是盲目点击。

## 3. 范围

### 3.1 包含

- 监控当前文档学习进度并自动跳下一章节；
- 固定 60 秒节奏的自动翻页；
- 可拖拽浮窗：状态、进度、暂停/继续、手动跳章、演练模式、屏幕常亮、通知；
- 刷新/重新进入页面后恢复启用状态；
- 单标签页执行锁、页面结构异常告警、无进展告警、完成通知；
- 纯逻辑单元测试与构建脚本。

### 3.2 不包含

- 自动参加模拟考/正式考试、自动答题；
- 伪造鼠标、键盘事件或绕过平台的反作弊/防挂机校验；
- 调用平台内部接口直接写学习时长；
- 代理账号、保存或输入密码；
- 适配 USTC 以外的其他学习平台；
- 云端同步、多设备协同；
- 当总时长未达标而章节已全部完成时，自动循环重刷章节。

## 4. 方案选择

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 油猴脚本 | 复用浏览器登录态；无需额外进程；易安装、易调试 | 需要保持标签页打开；依赖 DOM 结构 | **采用** |
| 浏览器扩展 | 后台生命周期更稳、可全局通知 | 开发与安装成本高；对单站点过重 | 否决 |
| Playwright 自动化 | 可完全无人值守 | 需独立浏览器与 Node 环境；重新登录成本高；行为更像机器人 | 否决 |

## 5. 技术架构

```
sysaq-userscript/
├─ src/
│  ├─ config.js        # 时间常量
│  ├─ core.js          # 纯逻辑：解析、判定、选择下一章、翻页决策
│  ├─ selectors.js     # 站点选择器与文本常量
│  ├─ settings.js      # 设置持久化与单标签页租约
│  ├─ runner.js        # 状态机与计时调度（尽量少依赖 DOM）
│  ├─ dom.js           # DOM 读取与白名单点击
│  ├─ panel.js         # Shadow DOM 浮窗
│  ├─ panel.css        # 浮窗样式（构建时内联）
│  ├─ services.js      # 提示音/系统通知/屏幕常亮/标题前缀
│  └─ main.js          # 启动入口：初始化、路由监听、装配各模块
├─ tests/
│  ├─ core.test.js     # node:test 单元测试
│  ├─ settings.test.js
│  └─ runner.test.js
├─ build.mjs           # esbuild 打包，注入油猴元数据头
├─ package.json
└─ dist/
   └─ sysaq-auto-study.user.js
```

- 语言/运行时：原生 JavaScript（ES2022），无框架；Node.js 仅用于构建和测试。
- 构建：esbuild 打包为 IIFE，`banner` 写入 `==UserScript==` 元数据；CSS 以文本形式内联。
- 测试：`node --test` 只测 `core.js` 等纯逻辑，不引入 jsdom。
- 油猴元数据：

```js
// ==UserScript==
// @name         实验室安全平台自动学习
// @namespace    local.sysaq
// @version      0.1.0
// @description  自动翻页、按学习进度切换下一章节
// @match        https://sysaq.ustc.edu.cn/lab-study-front/examTask/*
// @run-at       document-idle
// @noframes
// @grant        none
// ==/UserScript==
```

`@grant none` 使脚本运行在页面上下文，可直接使用 `localStorage`、`Notification`、`navigator.wakeLock`；所有网络请求仍由平台页面自身发起，脚本不调用任何接口。

## 6. 运行时行为

### 6.1 状态机

| 状态 | 含义 | 自动点击 |
|---|---|---|
| `WAIT_PAGE` | 等待章节列表、进度面板和阅读器就绪 | 否 |
| `RUNNING` | 监控进度、按 60 秒翻页 | 是（翻页） |
| `ADVANCING` | 已触发下一章，等待切换完成 | 否（防重复） |
| `PAUSED` | 用户暂停 | 否 |
| `COMPLETED` | 没有下一章节 | 否 |
| `ERROR` | 结构/加载/会话异常 | 否，页面恢复后自动退出 |

首次安装默认 `PAUSED`，面板主按钮显示“启用”，由用户点击后进入 `WAIT_PAGE → RUNNING`。用户启用后写入设置，刷新或重新进入学习页自动恢复 `WAIT_PAGE → RUNNING`；暂停后主按钮显示“继续”。

### 6.2 主循环

- **UI 刷新**：每 1 秒读取并更新面板（进度、翻页倒计时）。
- **进度判定**：每 5 秒解析一次 `.positionRight`。
- **翻页**：每 60 秒尝试一次“下一页”；只在 `RUNNING`、阅读器存在、当前页 < 总页数时执行。到达最后一页后停止翻页，不循环。切换文档后重置翻页计时与页码基线。
- **完成判定**：
  1. 解析出 `learnedSec`、`requiredSec`；
  2. 要求 `requiredSec > 0` 且 `learnedSec >= requiredSec`；
  3. 进入 30 秒确认期，期间每次检查仍满足条件才继续；
  4. 确认期结束后进入 `ADVANCING`。
  - 30 秒确认期用于覆盖一次约 60 秒的上报心跳与可能的数值回退；确认期内数值回退则取消跳章。
- **跳章**：
  1. 记录当前 `li.panelItem.activeitem` 在列表中的索引；找不到激活项则进入 `ERROR`，不猜测当前章节；
  2. 找下一个兄弟 `li.panelItem`；不存在则进入 `COMPLETED`；
  3. 点击下一项（演练模式只记录不点击）；
  4. 最多重试 3 次，退避 2s / 5s / 10s，判定条件为 `activeitem` 转移且 `.pptbox` 中重新出现 canvas；
  5. 成功后等待 10 秒稳定期，等新文档进度值重置，再回到 `RUNNING`；
  6. 三次仍未切换则进入 `ERROR`。
- **完成**：`COMPLETED` 状态不自动跳转其他页面；修改标题前缀、面板变蓝、提示音（可选系统通知）各触发一次。若顶部总时长仍未达标，面板如实显示，由用户决定后续操作。

### 6.3 时长解析

- 支持 `m:ss`、`mm:ss`、`h:mm:ss`、`hh:mm:ss`，以及带前导空格的形式。
- 解析失败或要求时长为 0：不跳章，状态转 `ERROR` 并提示“无法判断完成”。
- 总时长与单篇要求时长分开处理，互不替代。

### 6.4 自动点击白名单

脚本只会主动点击两类元素：

1. 章节列表中的 `li.panelItem`（跳章）；
2. 分页栏中文本为“下一页”的 `.btn-a`（翻页）。

不查询、不点击“模拟考试”“开始考试”或任何答题控件。若页面不再同时具备章节列表与 `.positionRight`（例如进入考试页），状态转 `ERROR` 并停止自动操作。

## 7. 浮窗 UI

- 右下角固定定位，Shadow DOM 隔离样式；可拖拽、可收起为小标题条；位置与收起状态持久化。
- 结构：

```
┌ 自动学习   ● 运行中        ─  × ┐
│ 当前章节   通识类实验室安全知识-水电安全 │
│ 本文档     12:01 / 30:00           │
│            ▓▓▓▓▓░░░░░░░░  40%      │
│ 总时长     1:55:48 / 3:00:00       │
│ 翻页       3 / 22                   │
│ 下一步     继续学习，预计 17:59 后跳章 │
├────────────────────────────────────┤
│ [暂停]  [立即跳下一章]               │
│ [ ] 演练模式   [ ] 屏幕常亮   [ ] 通知 │
└────────────────────────────────────┘
```

- 状态色：运行中绿、暂停灰、完成蓝、异常红；同时把状态写到 `document.title` 前缀（`[学习中]`/`[已暂停]`/`[已完成]`/`[需处理]`），切到后台也能识别。
- “暂停/继续”控制所有自动点击；暂停期间面板仍实时刷新进度。
- “立即跳下一章”走与自动跳章相同的校验和重试流程，用于人工验证。
- “演练模式”只把计划动作写入面板和 console，不产生点击。
- “屏幕常亮”请求 `navigator.wakeLock.request('screen')`；不支持或失败时降级为文字提示。
- “通知”仅在用户点击开关时申请权限；被拒绝时用提示音 + 标题前缀兜底。
- 所有设置存 `localStorage`，读取失败时回退默认值。

## 8. 持久化与并发

- 存储键：
  - `sysaq-auto-study:settings:v1`：`{ enabled, dryRun, keepAwake, notify, panel: { right, bottom, collapsed }, version }`
  - `sysaq-auto-study:lease:v1`：`{ tabId, ts }`
- 单标签页租约：运行中的标签页每 5 秒续约；无租约或租约超过 15 秒未续则抢占。非持有者显示“另一标签页正在自动学习”，不执行任何自动操作。暂停、完成、页面卸载时释放租约。
- 设置写入需容错，JSON 解析失败则删除该键并恢复默认。

## 9. 异常处理

| 场景 | 处理 |
|---|---|
| 15 秒内找不到章节列表/进度面板/阅读器 | `ERROR`，红色提示“页面结构未识别，平台可能改版”；持续只读检查，页面恢复后自动继续，不点击 |
| 要求时长为 `00:00` 或解析失败 | 不跳章，`ERROR` 提示“无法判断完成” |
| 点击下一章无反应 | 2s/5s/10s 退避重试 3 次；仍失败则 `ERROR`，不继续点击 |
| 新文档未加载完 | 10 秒稳定期；等 `activeitem`、canvas、进度值都更新后再判定 |
| 已学习 10 分钟无增长 | 面板黄色告警“学习进度未增长，请检查标签页可见性/网络”；不暂停，继续监控 |
| 标签页进入后台 | 提示“后台标签页可能暂停计时，请保持此标签页可见”；不伪造活动事件 |
| 会话过期/跳转登录页 | 登录页不在 `@match` 范围，脚本不运行；返回学习页后按设置自动恢复；若进度持续缺失则 `ERROR` |
| 多标签页同时打开 | 租约机制保证只有一个标签页执行自动操作 |
| 考试/非学习页面 | 选择器不匹配或点击白名单之外的情况一律不动作 |
| 存储损坏 | 回退默认设置，不阻塞脚本 |
| Wake Lock 失败 | 降级提示，不影响学习流程 |

## 10. 测试方案

### 10.1 单元测试（node:test）

- `parseDuration`：`12:01`、`1:02:03`、`01:55:48`、空值、非法值。
- `isComplete`：达标、未达标、要求为 0、已学习超过要求。
- `pickNextIndex`：中间项、最后一项、无激活项。
- `shouldFlip`：到达间隔、最后一页、暂停状态、文档未就绪。
- `formatDuration` / `progressPercent` 等展示辅助函数。

命令：`npm test`

### 10.2 演练模式验证

在真实学习页开启“演练模式”，至少观察 2 次检查周期，确认：

- 章节名、已学习/要求学习、总时长、页码与页面一致；
- 到时计划翻页，但不实际翻页；
- 达标时计划跳章，但不实际点击。

### 10.3 人工端到端检查

1. 安装 Tampermonkey 与构建产物，打开学习页，浮窗出现且默认暂停；
2. 启用后 60 秒自动翻一页，最后一页停止；
3. 用“立即跳下一章”验证 SPA 切换、进度重置、翻页计时重置；
4. 等待一篇文档自然达标，确认 30 秒确认期后自动切到下一章；
5. 在最后一章完成后确认停止、标题变化、提示音/通知各一次；
6. 暂停后确认不再翻页和跳章；
7. 刷新页面确认启用状态与面板位置恢复；
8. 开两个标签页确认只有一个执行。

### 10.4 构建验证

- `npm run build` 生成 `dist/sysaq-auto-study.user.js`；
- 文件头包含完整的油猴元数据；
- 在 Tampermonkey 中无语法错误、无控制台异常。

## 11. 安装与使用

1. Chrome/Edge 安装 Tampermonkey 扩展；
2. 打开 Tampermonkey 管理面板 → 添加新脚本 → 粘贴 `dist/sysaq-auto-study.user.js` 内容并保存；
3. 打开学习详情页，右下角浮窗出现，点击“启用”；
4. 保持该标签页可见并让电脑不休眠；需要时开启“屏幕常亮”；
5. 全部完成后按提示音/系统通知处理，不自动进入考试。

## 12. 风险与限制

- **选择器依赖**：平台升级会导致识别失败；集中管理选择器并显式报错，不静默乱点。
- **后台计时未知**：未验证后台标签页是否继续累计；工具提示保持可见，不做规避性伪造。
- **要求总时长与单篇之和不一致**：工具按单篇达标跳章；章节耗尽但总时未达标时如实提示，不自动循环。
- **翻页节奏固定**：每 60 秒一页，22 页约 22 分钟，与 30 分钟要求时长接近；到最后一页后剩余时间仅保持打开。
- **学习效果**：自动播放不替代实际阅读，仅供在需要时减少手动操作。

## 13. 验收标准

1. 面板在进入学习页 5 秒内显示真实章节与进度；
2. 当前文档达标并经过确认期后，15 秒内自动进入下一章；
3. 每 60 秒翻一页，最后一页停止，切换文档后重置；
4. 最后一章完成后不再有任何自动点击，并发出一次完成通知；
5. 暂停、演练模式下无自动点击；
6. 单测全部通过，构建产物可直接安装；
7. 刷新后恢复启用状态，多标签页只有一个执行；
8. 全程不点击任何考试按钮，不伪造用户活动事件。

## 14. 后续可选项（不在本次范围）

- 可配置翻页节奏与确认期；
- 章节全部完成后的策略（如保持最后一篇打开以补足总时长）；
- 适配其他使用相同平台的学校；
- 独立扩展版与跨设备状态同步。
