# 实验室安全教育平台自动学习

一个运行在南七技校实验室安全教育平台学习页的 Tampermonkey 油猴脚本：自动每 60 秒翻一页，当前文档达到要求学习时长后自动切换到下一章，全部章节完成后停止并提示。

脚本只在本地浏览器中运行，不调用平台接口，不保存账号信息，也不对任何考试或答题控件做操作。

- 目标站点：`https://sysaq.ustc.edu.cn/lab-study-front/examTask/*`
- 版本：`0.1.0`
- 运行环境：Chrome / Edge（建议 Chromium 138 及以上）+ Tampermonkey 5.x
- GitHub 仓库：<https://github.com/nefelibatta/sysaq-auto-study>
- 构建产物：`dist/sysaq-auto-study.user.js`（已包含在仓库中）

## 快速开始

1. 安装 Tampermonkey（篡改猴）扩展。
2. Chrome 138+ / Edge 138+：在扩展详情页开启 **“允许用户脚本”**（Allow User Scripts）。
3. 从 [GitHub 仓库](https://github.com/nefelibatta/sysaq-auto-study) 下载 `dist/sysaq-auto-study.user.js`，导入 Tampermonkey。
4. 打开学习详情页，右下角出现“自动学习”浮窗后点击 **“启用”**。

> 只把扩展本身“启用”是不够的。Chrome/Edge 138 起，MV3 用户脚本还需要单独打开“允许用户脚本”，否则脚本不会执行，浮窗也不会出现。

## 功能

- **自动翻页**：每 60 秒点击一次“下一页”；到达最后一页后停止，不循环。
- **自动跳章**：当前文档“已学习 ≥ 要求学习”并持续 30 秒后，自动点击下一章。
- **跳章校验**：确认当前章节已切换、阅读器 canvas 已重新出现，再等待 10 秒稳定期。
- **浮窗面板**：显示当前章节、本文档进度、总时长、页码和下一步；可拖拽、可收起，位置会保存。
- **手动控制**：启用 / 暂停 / 继续、立即跳下一章。
- **演练模式**：只把计划中的翻页、跳章写入面板和 console，不产生实际点击。
- **屏幕常亮**：通过 `navigator.wakeLock` 请求屏幕常亮，失败时只提示、不影响学习。
- **完成提醒**：提示音 +（可选）系统通知 + 标题前缀，完成通知只触发一次。
- **异常告警**：页面结构缺失、要求时长为 0、10 分钟进度无增长、切换失败等都会在面板提示。
- **单标签页执行**：多个标签页打开同一学习页时，只有持有租约的标签页会自动操作。
- **刷新恢复**：启用状态、面板位置和选项保存在 `localStorage`，刷新后自动恢复。

## 安全边界

脚本只会主动点击两类元素：

1. 左侧章节列表项 `li.panelItem`；
2. 分页栏中文本为“下一页”的 `.pageBtn span.btn-a`。

脚本不会：

- 点击“模拟考试 / 开始考试”或任何答题控件；
- 调用平台接口、读取或保存密码、Cookie；
- 伪造鼠标、键盘或页面可见性事件；
- 绕过平台的反作弊、防挂机或其他校验。

脚本本身不发起网络请求；学习时长的上报由平台页面自身完成。请遵守平台使用规定，脚本仅用于减少手动操作，不替代实际学习。

## 安装

### 1. 安装并放行 Tampermonkey

1. 在浏览器中安装 Tampermonkey（篡改猴）扩展。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），找到 Tampermonkey。
3. 进入 **详情**，打开 **“允许用户脚本”**（Allow User Scripts，部分版本显示为“允许运行用户脚本”）。
4. 建议点击扩展卡片上的刷新按钮，或重启浏览器，让扩展重新加载。

### 2. 获取并安装脚本

任选一种方式：

- **从 GitHub 下载**：打开仓库中的 `dist/sysaq-auto-study.user.js`，点击 **Raw** 或下载按钮保存文件，再按下面的“导入文件”安装。
- **在线安装**：仓库为公开仓库时，直接打开
  `https://raw.githubusercontent.com/nefelibatta/sysaq-auto-study/main/dist/sysaq-auto-study.user.js`，
  Tampermonkey 会自动弹出安装页；私有仓库请用下载后导入的方式。
- **导入文件**：Tampermonkey 管理面板 → 实用工具 → 导入文件 → 选择 `sysaq-auto-study.user.js` → 安装。
- **粘贴安装**：Tampermonkey 管理面板 → 添加新脚本 → 粘贴 `sysaq-auto-study.user.js` 的全部内容 → `Ctrl+S` 保存。

### 3. 开始使用

1. 打开学习详情页（`.../examTask/...`）。
2. 右下角出现“自动学习”浮窗，默认状态为“已暂停”。
3. 点击 **“启用”**，状态先变为“等待页面”，页面就绪后进入“运行中”。
4. 建议保持该标签页可见；需要时勾选“屏幕常亮”。

## 使用说明

### 面板

```text
┌ 自动学习   ● 运行中        － ┐
│ 当前章节   通识类实验室安全知识-水电安全 │
│ 本文档     12:01 / 30:00            │
│            ▓▓▓▓▓░░░░░░░░  40%       │
│ 总时长     1:55:48 / 3:00:00        │
│ 翻页       3 / 22                   │
│ 下一步     还需 17:59，达标后跳章     │
├─────────────────────────────────────┤
│ [暂停]  [立即跳下一章]               │
│ [ ] 演练模式  [ ] 屏幕常亮  [ ] 通知  │
└─────────────────────────────────────┘
```

- 拖动标题栏可移动面板；点 `－` / `＋` 收起或展开。
- **启用 / 暂停 / 继续**：控制所有自动点击。暂停期间面板仍会刷新真实进度。
- **立即跳下一章**：不要求当前文档达标，但会走与自动跳章相同的校验、重试和稳定期流程；已经是最后一章时会提示。
- **演练模式**：不点击，仅记录“将翻页”“将跳章”等计划动作，适合首次验证。
- **屏幕常亮**：仅在页面可见时生效；浏览器不支持或请求失败时给出提示。
- **通知**：勾选时申请系统通知权限；启用脚本时若该选项已开启，也会再次确认权限。被拒绝时以提示音和标题前缀兜底。
- 当另一个标签页持有执行租约时，本标签页会提示“另一标签页正在自动学习”，并拒绝启用。

### 状态与标题前缀

| 面板文字 | 内部状态 | 含义 |
| --- | --- | --- |
| 已暂停 | `PAUSED` | 不执行任何自动操作 |
| 等待页面 | `WAIT_PAGE` | 等待章节列表、进度和阅读器就绪 |
| 运行中 | `RUNNING` | 监控进度，按 60 秒节奏翻页 |
| 切换章节中 | `ADVANCING` | 已触发下一章，正在校验和重试 |
| 全部完成 | `COMPLETED` | 没有下一章，已停止 |
| 需处理 | `ERROR` | 页面结构、进度或切换异常 |

标签页标题会带上对应前缀：`[等待中]`、`[学习中]`、`[已暂停]`、`[已完成]`、`[需处理]`。

### 运行时序

| 项目 | 间隔 / 次数 |
| --- | --- |
| 面板刷新与主循环 | 1 秒 |
| 学习进度判定 | 5 秒 |
| 自动翻页 | 60 秒 |
| 达标确认期 | 30 秒 |
| 跳章失败重试 | 2 秒 / 5 秒 / 10 秒，共 3 次 |
| 新章节稳定期 | 10 秒 |
| 页面结构超时 | 15 秒 |
| 进度无增长告警 | 10 分钟 |
| 多标签页租约续约 | 5 秒续约，15 秒过期 |

### 完成与跳章

1. 从 `.positionRight` 解析“已学习 / 要求学习”时长。
2. 要求时长必须大于 0，且已学习时长达到要求时长。
3. 连续满足 30 秒后触发跳章；期间数值回退则取消。
4. 点击下一章后，确认当前章节索引已切换且阅读器 canvas 已出现。
5. 成功后等待 10 秒，让新文档进度重置，再回到“运行中”。
6. 如果新章节进度没有重置，面板会给出提醒，但仍继续监控。
7. 最后一章达标后进入“全部完成”，停止自动点击，并只发一次完成提醒。

页面结构或进度异常会进入“需处理”；结构恢复后大多会自动继续。跳章失败（`advance-failed`）不会自动重试，需要点击面板上的 **“重试”**。

## 数据存储

脚本只使用当前站点的 `localStorage`：

| 键 | 内容 |
| --- | --- |
| `sysaq-auto-study:settings:v1` | `enabled`、`dryRun`、`keepAwake`、`notify`、面板位置与收起状态 |
| `sysaq-auto-study:lease:v1` | 单标签页执行租约（`tabId`、时间戳） |

默认设置：`enabled: false`、`dryRun: false`、`keepAwake: false`、`notify: false`，面板距右下角 16px。

不会上传、同步或发送任何数据。

## 构建与测试

需要 Node.js 18+。

```bash
npm install
npm test        # 31 项单元测试
npm run build   # 重新生成 dist/sysaq-auto-study.user.js
```

构建使用 esbuild，将 `src/main.js` 打包为 IIFE，并把 CSS 内联进产物。仓库已包含构建产物；修改 `src/` 后请重新运行 `npm run build` 并提交更新后的 `dist/`，不要直接编辑产物。

## 常见问题

### 浮窗没有出现

1. **最常见原因**：Chrome/Edge 138+ 没有为 Tampermonkey 打开“允许用户脚本”。打开扩展详情页开启后，刷新扩展或重启浏览器，再刷新学习页。
2. 确认脚本已在 Tampermonkey 管理面板中安装并处于启用状态。
3. 确认当前地址匹配 `https://sysaq.ustc.edu.cn/lab-study-front/examTask/*`；登录页不在匹配范围。
4. 安装脚本后需要刷新一次学习页，已经打开的旧标签页不会自动注入。
5. 如果仍然没有，检查浏览器控制台是否有报错，或平台结构是否已改版。

### 面板显示 `--` 或进入“需处理”

页面尚未加载完成，或平台 DOM 结构发生变化。脚本会在 15 秒后提示“页面结构未识别”；平台恢复后会自动继续。选择器集中在 `src/selectors.js`，平台改版时需要更新这里。

### 不自动翻页

检查面板状态：

- 是否处于“已暂停”；
- 是否开启了“演练模式”；
- 是否有另一个标签页持有租约；
- 是否已到最后一页；
- 是否识别到 `.pptbox` 阅读器和页码。

### 不自动跳章

- 当前文档尚未达到要求时长；
- 刚达标，仍在 30 秒确认期内；
- 页面处于“需处理”；
- 切换被平台拦截，或 `.pptbox` 中没有出现 canvas。

可以先开启“演练模式”观察计划动作，或用“立即跳下一章”手动验证。

### 两个标签页同时打开

脚本通过 `localStorage` 租约保证只有一个标签页执行自动操作。另一个标签页会显示“另一标签页正在自动学习”；暂停、完成或关闭持有租约的标签页后，租约释放。

### 通知或屏幕常亮不生效

- 通知需要浏览器授权；被拒绝时使用提示音和标题前缀兜底。
- 屏幕常亮依赖 `navigator.wakeLock`，浏览器不支持或标签页不可见时会失败。

## 限制

- 依赖目标站点的 DOM 结构，平台改版可能导致选择器失效。
- 未验证后台标签页是否继续累计学习时长，建议保持学习页可见。
- 翻页节奏固定为 60 秒；到达最后一页后只保持打开，不循环。
- 按“单篇文档达标”跳章；如果总要求时长大于各章要求之和，章节耗尽后不会自动循环重刷。
- 不自动参加考试、不自动答题。
- 仅在 USTC 实验室安全教育平台上验证过，不保证适配其他平台。
